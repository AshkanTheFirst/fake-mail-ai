## ⚡ Features

- **🌐 15 Curated Disposable Email Providers:** Direct links, descriptions, tags, and one-click launch for:
  - 🐢 22.do
  - 🐝 temp.tf
  - 🐡 tmail.io
  - 🦩 dispose.lol
  - 🦌 boomlify.com
  - 🐦‍⬛ emailtick.com
  - 🦘 emailtick (Mirror)
  - 🐐 tempgbox.net
  - 🕷️ temp-inbox.me
  - 🐎 tempmailg.com
  - 🐷 mailticking.com
  - 🐋 emailnator.com
  - 🐊 tempmailhub.org
  - 🐓 tempgmailer.com
  - 🐶 temporary-mail.net

- **🤖 AI Synthetic Mail Studio:**
  - **Instant Burner Generator:** Randomized high-anonymity addresses with domain selection.
  - **Gmail Dot-Trick Engine:** Generate unlimited alias combinations (dots, plus-tags, `@googlemail.com`) that deliver to the same inbox.
  - **Full Persona Generator:** Instant synthetic identities with secure passwords for quick registration.

- **🎨 Futuristic Neo-AI UI:** Glassmorphism, animated glow effects, search & category filtering, and mobile responsive design.

## 💻 Local Usage

You can also run it locally:
```bash
# Clone the repository
git clone https://github.com/AshkanTheFirst/fake-mail-ai.git

# Open index.html directly in any browser, or run via Node:
npm install
npm start
```
